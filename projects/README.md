# projects/ — הפרויקטים של הילדים

כאן נשמרים הסרטונים/הסצנות שמישהו בנה:
כל האובייקטים, החומרים, התאורה, המצלמה וכל הפריימים של ציר הזמן.

- שם הקובץ הוא שם הפרויקט.
- אפשר לשמור כמה פרויקטים במקביל ולפתוח כל אחד מהם מהכפתור "פתח פרויקט".
- הקובץ הוא טקסט קריא — אפשר לגבות אותו בענן או בהעתקה לכונן.
