# materials/ — פריסטים של חומרים

כאן נשמור חומרים מוכנים שהילדים יוכלו להחיל על אובייקט בלחיצה:
עץ, מתכת, פלסטיק צבעוני, בד, זכוכית, קרטון, קרמיקה...

בשלב 4 (עריכת אובייקט) המנוע יטען את כל הקבצים שכאן ויציג אותם
כרשימת פריסטים בפאנל המאפיינים.

לכל פריסט: שם בעברית + צבע, חספוס (Roughness), מטאלי (Metallic).
טקסטורה (אופציונלי) תיקח מ-`assets/textures/`.
