# thumbs/ — תמונות ממוזערות לבנק האסטים

תמונה אחת לכל אסט, בגודל **256×256**, בפורמט PNG.
שם הקובץ חייב להיות **זהה** לשם המודל (בלי הסיומת `.glb`):

```
assets/models/school_chair.glb
assets/models/thumbs/school_chair.png   ← התמונה שתופיע בבנק
```

לא חובה: אם אין תמונה, המנוע יצלם את המודל אוטומטית וישמור כאן תמונה.
אם אתה מכין תמונה בעצמך — רקע שקוף, המודל ממורכז, זווית תלת-רבע.
