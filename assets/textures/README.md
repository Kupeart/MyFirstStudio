# textures/ — טקסטורות

תמונות PNG בשימוש החומרים והפריסטים:
עץ, לבנים, דשא, אריחים, בד...

כללי אצבע:
- גודל עד 1024×1024
- טקסטורה שהיא "משטח" (רצפה/קיר) צריכה להיות **ניתנת לריצוף** (seamless)
- שם באנגלית קטן עם קו תחתון: `wood_oak.png`

הטקסטורות של המודלים שלך מבלנדר יכולות להישאר ארוזות בתוך ה-`.glb` —
אין חובה להעביר אותן לכאן.
