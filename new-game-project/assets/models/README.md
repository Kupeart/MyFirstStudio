# models/ — המודלים שלך מבלנדר

כאן שמים קובץ **`.glb`** אחד לכל אסט. המנוע סורק את התיקייה הזו אוטומטית.

## תזכורת לייצוא נכון

| דרישה | הערך |
| --- | --- |
| פורמט | `.glb` (glTF Binary) — `File ▸ Export ▸ glTF 2.0 (.glb/.gltf)` |
| סקאלה | 1 יחידה = 1 מטר |
| טרנספורמים | `Ctrl+A ▸ Apply All Transforms` לפני ייצוא |
| Origin | תחתית-מרכז האובייקט |
| כיוון קדימה | ציר **+Y** בבלנדר |
| פוליגונים | עד ~20k לרהיט, עד ~60k לדמות |
| מיקום האובייקט | סביב נקודת הראשית (0,0,0) — לא רחוק ממנה |

## הקטגוריה = שם התיקייה

התיקייה שבה יושב המודל קובעת לאן הוא ייכנס בבנק:

```
assets/models/Furnatures/SimpleTable/SimpleTable.glb   →  קטגוריה "רהיטים"
assets/models/Nature/tree.glb                          →  קטגוריה "טבע"
```

## שם הקובץ

שם הקובץ הופך להיות שם האסט בבנק, לכן:

- אותיות קטנות באנגלית, מפריד קו תחתון: `school_chair.glb`
- שם ברור: `wooden_table.glb` עדיף על `obj_003.glb`

## תמונות ממוזערות (לא חובה)

אם תרצה תמונה יפה משלך לבנק, שים PNG בגודל 256×256 בתיקיית `thumbs/` עם **אותו שם בדיוק**:

```
assets/models/wooden_table.glb
assets/models/thumbs/wooden_table.png
```

אם אין תמונה — המנוע יצלם אחת אוטומטית מהמודל.
